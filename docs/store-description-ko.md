## 상세 설명

**Land of Magic**은 Godot 4로 제작된 싱글플레이어 저택 탐색 어드벤처입니다. 당신은 고딕풍 저택을 방 하나씩 이동하며 오브젝트를 조사하고 단서를 수집하고 다음 목적지를 결정합니다. 이 게임의 핵심은 저택이 정적이지 않다는 것입니다. 당신이 발견한 모든 단서는 아직 들어가지 않은 방들의 상태를 변화시킵니다. 인접한 각 방의 위험·보상 설명이 탐색 진행에 따라 실시간으로 갱신되어, 모든 문이 무작위 선택이 아닌 의미 있는 전략적 결정이 됩니다.

핵심 루프는 1분 안에 파악할 수 있도록 의도적으로 간결하게 설계되었습니다. 방에 들어가고, 오브젝트 1~2개를 조사하고, 단서 패널이 갱신되는 것을 확인한 뒤, 더 깊이 탐색할지 현재 방에서 더 조사할지 결정합니다. 이 리듬 덕분에 Land of Magic은 20~30분 세션에 이상적입니다. 발견의 만족감을 느끼기에 충분히 길고, 일상으로 돌아가기 전 자연스러운 종착점을 찾기에 충분히 짧습니다. 방치형 자동 전투와 로그라이트 성장에 익숙한 플레이어라면 친숙한 축적의 감각을 느끼면서도, 방 선택 레이어가 수동적인 게임에서는 보기 힘든 진짜 의사결정의 무게를 더해준다는 것을 발견하게 됩니다.

Land of Magic은 Godot 4.3의 Forward Plus 렌더링 파이프라인을 기반으로 제작되어, 폭넓은 하드웨어 범위에서 깔끔한 시각적 품질을 제공합니다. 오토로드 아키텍처(SaveData, GameState)가 세션 간 탐색 상태를 안정적으로 저장하므로, 현실에 의해 중단된 런도 처음부터 다시 시작할 필요가 없습니다. 저택은 발견한 단서에 따라 계속 진화하기 때문에, 같은 시작 복도에서 두 번째, 세 번째 런을 시작하더라도 완전히 다른 방향으로 이야기가 전개됩니다.

## 주요 특징

- **단서 기반 방 동적 변화** — 오브젝트 조사는 정보 보상에 그치지 않습니다. 탐색하지 않은 방들의 위험·보상 프로필을 실제로 바꿉니다.
- **의미 있는 문 선택** — 현재 단서 상태에 따라 갱신된 설명이 각 인접 방에 표시됩니다. 저택을 관통하는 두 개의 똑같은 경로는 없습니다.
- **세션 친화적 페이싱** — 20~30분 세션을 위한 핵심 루프 설계. 명확한 휴식 지점과 안정적인 저장 상태.
- **로그라이트 성장 레이어** — 경험치와 레벨업 시스템이 탐색 깊이를 보상하면서도 신중한 플레이어에게 불이익을 주지 않습니다.
- **Godot 4.3 네이티브 성능** — PCK 내장 경량 빌드로 Windows 환경에서 추가 설치 없이 실행 가능.
- **자동 전투 + 탐색 하이브리드** — 방치형·자동 전투의 낮은 진입 장벽에 단서 기반 탐색의 전략적 질감을 결합.
