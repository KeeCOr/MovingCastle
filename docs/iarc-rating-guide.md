# Land of Magic (LivingMansion) — IARC Rating Guide

## What is IARC?

The International Age Rating Coalition (IARC) provides automatic age ratings across all major digital storefronts. Steam uses IARC for store compliance. The questionnaire takes 10–15 minutes.

**IARC Portal:** https://www.globalratings.com/

## Expected Rating Output

| Region | Expected Rating | Notes |
|--------|----------------|-------|
| ESRB (US) | E10+ or T | Gothic atmosphere may push to T |
| PEGI (Europe) | PEGI 7 | Mild fear/horror themes |
| USK (Germany) | USK 6 | Dark themes but no violence |
| CERO (Japan) | A or B | Likely A (All Ages) |
| ACB (Australia) | PG | Mild horror setting |
| GRAC (Korea) | 12+ | Gothic atmosphere |

Land of Magic is primarily a peaceful exploration game with mild gothic atmosphere. No combat, blood, or explicit horror. Expect teen-friendly ratings in most regions.

## Steam Store Setup

1. Steamworks App Admin → Store Page → Ratings
2. Click "Manage Ratings" → "Complete Questionnaire"
3. Answer using the table above
4. Submit — IARC generates ratings within minutes
5. Ratings appear on the store page automatically
